**THEOREM R1.** Fix a period n, a lag Δ (indeed any n-periodic
nondecreasing schedule), and constants ε > 0, M < ∞. On the convex
set K_n(ε,M) = {(h,Γ) ∈ L_n : Γ ⪯ MI, n(ω) := Γ − hPh\* ⪰ εI a.e.}
— where L_n is the **linear** space of period-n moment kernel pairs
— the process-rate functional is finite and **jointly convex**. The
set **carries no window length anywhere**.

Proof in four steps: (0) Collapse plus the shifted frame, where Δ
enters as a **unimodular phase** — a linear invertible change of
coordinates mapping K_n onto itself, so convexity is Δ-independent;
(1) **blocking by n**, making the pair a stationary 2n-variate
process; (2) **matrix Szegő/Wiener–Masani, the only analytic input**,
cited with its hypotheses verified on K_n; (3a) the block leg convex
by matrix quadratic-over-linear composition; (3b) the leak leg
convex because each conditional variance is an **infimum of affine
functions** — the same admissibility structure the Ψ certificate
used internally. Plus the **Scoping Lemma**: step-(A) periodizations
have blocked noise spectrum constant in frequency, their shifts
conjugate it by a unitary block cyclic shift, so one (ε,M) serves
the whole orbit and its convex hull.

**WHAT THE PROOF REPLACES.** The recorded three-step justification
had two bad steps: the finite-window functional's convergence to the
process rate is a **genuine gap** (a different functional, needing
its own boundary-charge argument — measured true, not proved), and
the pointwise-limit step is **ill-posed as worded** (the domain moves
with the window length). **This route uses neither.**

**THE CONSEQUENCE.** L^∞(Δ) ≥ Ψ(D;Δ) ≥ LB(Δ) for Δ = 0, 1, 2 is
**unconditional** — no (H\*), (H\*\*), (H\*\*\*), (D), (F), no boundary
charge, no (R1) as a hypothesis, no (R2) — at margins
+0.0147817164 / +0.0040574952 / +0.0007968190. **"Unconditional"
attaches to the CHAIN, never to the Ψ VALUE**, which remains a
