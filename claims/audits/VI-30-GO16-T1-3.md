## The error, independently confirmed (N1)

**What is wrong.** Theorem 3 says the water level sits at a breakpoint t* = μ_j, and that the
tie λ_k(G*) = λ_{k+1}(G*) holds iff the contested set is nonempty. But the level ranges over
t ≥ 0, and t = 0 is an endpoint. The minimum can sit there (a **blackout regime**): every
shieldable coordinate is reproduced at ρ_i = 0, and only conceded ones are revealed.

**The witness.** μ = (5, 3, 2, 1), s² = (10, 0.1, 0.1, 0.1), λ = 1, k = 2. It satisfies:
- (G1): the μ_i are distinct and positive;
- (G2): λμ_i ≠ s_i² for every i.

**Confirmed by me (the assistant), 2026-11-20, two ways:**
- The paper's own water-level function gives J(0) = 5.3, while
  J(μ_j) = 6.1167, 7.0333, 8.0 and 10.0.
- An independent brute-force minimization of the reduced program over ρ ∈ [0, 1]⁴ (3,000
  local starts, plus a 21⁴ grid) finds J* = 5.3 at ρ = (1, 0, 0, 0).

**The consequence.** G* has spectrum (5, 0, 0, 0). So λ₂ = λ₃ = 0, a tie, while the contested
set is empty. This falsifies four statements:
- "t* = μ_j";
- the "exhaustive two-regime alternative";
- "tie iff contested ≠ ∅";
- the proof's line "contested = ∅ ⇒ spectrum {μ_i}".

**Where the false statement also appears:**
- Theorem 5 (commuting scope), which states Theorem 3 "verbatim";
- the claim text of sealed registration GO-P-2026-090 (line 38: "tie iff contested").

**Why 090's governed run passed anyway.** Its gate V6 is circular by construction: it
checks Σθ = k against a slack defined as k − Σ. No instance it ran was in the blackout regime.

**The verifier's proposed fix.** Add a third regime, blackout (t* = 0). There, shieldable
coordinates take ρ_i = 0, with θ_i ∈ [s_i²/(λμ_i), 1]. The tie is then characterized as
"tie iff contested ∪ blacked-out ≠ ∅ (k < n)". This proposal has not yet been proved.

**Disposition:**
- Recorded as **NEG-17**.
- Theorem 3's iff clause, as sealed in 090, is refuted.
- The corrected theorem is owed (Track P: proof, a fresh R-IND-5 pass, and a net that includes
  blackout and contested-empty instances).
- 090's file is unchanged. The refutation is disclosed in its registry row and in the
  ledger.
